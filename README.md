# 🛠 Qoder Test Helper

> Chrome 浏览器扩展 - Web 应用测试辅助工具

一款专为 Web 测试人员设计的 Chrome 扩展，通过**元素选择**和**流程录制**两种工作流，快速生成结构化的测试问题报告，并内置 AI 深度分析提示词。

---

## ✨ 核心功能

### 🎯 元素问题工作流
点击页面元素 → 选择分类 → 填写描述 → 保存问题

适用于：UI 样式问题、元素显示异常、定位相关的 Bug

### 🔄 流程问题工作流
录制操作日志 → 执行页面操作 → 填写描述 → 保存问题

适用于：功能流程缺陷、操作断链、数据异常、性能卡顿

### 📄 智能报告生成
- **按页面分组**：同一页面的问题自动归类
- **全局编号**：问题跨页面连续编号
- **日志独立**：每个问题携带自己的操作日志
- **AI 提示词**：自动生成双路径分析提示词（架构分析 / 视觉设计评估）

### 📦 报告导出
- 复制 Markdown 到剪贴板（生成后自动复制）
- 下载 `.md` 文件
- 下载 `.zip` 压缩包（纯 JS 实现，无外部依赖）

## 🏗 问题分类体系

### 元素问题分类
| 分类 | 说明 |
|------|------|
| 🎨 UI/样式 | 元素显示异常、样式错位、布局问题 |
| ⚙️ 功能缺陷 | 功能不可用、交互异常、逻辑错误 |
| 📊 数据问题 | 数据展示错误、接口返回异常、数据不一致 |
| ⚡ 性能问题 | 页面加载慢、操作卡顿、资源占用高 |
| ✨ 新功能 | 新增功能需求、功能扩展、能力增强 |

### 流程问题分类
| 分类 | 说明 |
|------|------|
| 🔗 流程断链 | 流程中断、步骤缺失、跳转异常 |
| ⚙️ 功能缺陷 | 操作无响应、功能不可用、逻辑错误 |
| 📊 数据异常 | 提交失败、数据丢失、接口返回异常 |
| ⚡ 流程卡顿 | 操作延迟、加载缓慢、等待时间过长 |
| 💡 流程体验 | 步骤冗余、引导不清、操作不直观 |

## 🚀 安装使用

### 加载扩展
1. 克隆或下载本仓库
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择项目目录 `QTest`

### 使用流程
1. 在任意网页上点击扩展图标，打开悬浮面板
2. 选择工作流：
   - **元素问题**：点击页面元素进行标记
   - **流程问题**：开始录制后执行操作
3. 填写问题分类和描述
4. 可重复添加多个问题
5. 点击「生成测试报告」→ 自动复制到剪贴板

## 🤖 AI 分析双路径

### A. 功能/缺陷/数据/性能/新功能类
→ **架构层面深度分析**
- 架构现状诊断（模块划分、联动关系、数据流向）
- 逻辑链路追踪（定位异常层级）
- 架构合理性评估（API 设计、状态管理、技术栈匹配度）
- 涉及架构整改时：先给架构方案，再给缓解方案，最后给演进路线图

### B. UI/样式类
→ **视觉设计体系宏观分析**
- 页面规划与布局分析
- 元素功能定义审视
- 视觉体系评估（配色、字体、间距）
- 设计系统建议（Design Token、组件库抽象）

## 🛠 技术栈

| 技术 | 说明 |
|------|------|
| Chrome Extension Manifest V3 | 扩展规范 |
| Content Script | 注入悬浮面板到页面 |
| XPath | 元素定位 |
| MutationObserver | DOM 变化监控 |
| postMessage | 日志拦截通信 |
| Pure JS ZIP | 无依赖 ZIP 打包 |
